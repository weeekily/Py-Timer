# Py-Timer ⏱

A simple web-based countdown timer built with **Python** and **Flask**.  
You enter hours, minutes and seconds, and the app displays a live countdown in the browser.

## Features

- Input hours, minutes, and seconds
- Converts time to total seconds on the backend (Flask)
- Live countdown in the browser using a small JavaScript function
- Modern dark UI

> The UI layout and CSS were created with assistance from ChatGPT.

## Tech Stack

- Python 3
- Flask
- HTML
- CSS
- JavaScript (for the countdown logic in the browser)
